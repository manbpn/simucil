Import Siswa

Tambahkan atau perbarui banyak siswa sekaligus lewat file Excel/CSV.

Format file yang dibutuhkan

File Excel (.xlsx) atau CSV dengan baris pertama berisi judul kolom berikut (urutan bebas, huruf besar/kecil tidak masalah):

Nama KolomWajib?Keterangan
NISWajibNomor induk siswa, harus unik
NamaWajibNama lengkap siswa
KelasWajibHarus sama persis dengan nama kelas yang sudah ada di menu Data Kelas (contoh: XI-A)
Jenis KelaminOpsionalL / Laki-laki / P / Perempuan
Nama OrtuOpsionalNama orang tua/wali
No WA OrtuOpsionalNomor WhatsApp orang tua/wali

Siswa dengan NIS yang sudah ada akan diperbarui datanya (bukan dobel). Pastikan semua kelas yang dipakai di file sudah dibuat lebih dulu di menu Data Kelas.
